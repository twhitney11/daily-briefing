# The Daily Curiosity

A responsive, static newspaper archive. Published editions: October 8–18, 2026, with five original stories per edition.

GitHub Pages serves the root of `main`. No dependencies or build step. `index.html` is the latest edition; `archive.html` links every dated page.

Public editions omit personal references and images without established reuse rights, plus captions referring to those omitted images. Source links and remaining story text are retained.

New editions are not published automatically yet.
